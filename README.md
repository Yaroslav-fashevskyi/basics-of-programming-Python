Оголосіть клас з іменем Clock і визначте в ньому такі змінні та
методи:
● приватна локальна змінна time для зберігання поточного часу, ціле
число (своя для кожного об'єкта класу Clock з початковим значенням
0);
● публічний метод set_time(time) для встановлення поточного часу
(присвоює значення time приватній локальній властивості time, якщо
метод check_time(time) повернув True);
● публічний метод get_time() для отримання поточного часу з
приватної локальної змінної time;
● приватний метод класу check_time(time) для перевірки коректності
часу у змінній time (повертає True, якщо значення коректне, і False -
в іншому випадку).
Перевірка коректності виконується за критерієм: time має бути цілим
числом, більшим або дорівнювати нулю і меншим за 100 000.
Об'єкти класу Clock передбачається створювати наступним чином:

clock = Clock(time),

де time - ціле число.
Створіть об'єкт clock класу Clock і встановіть час, що дорівнює 4530.

# Завдання 2.
Оголосіть клас з іменем Money і визначте в ньому такі змінні та
методи:
● приватна локальна змінна money (цілочисельна) для зберігання
кількості грошей (своя для кожного об'єкта класу Money);
● публічний метод set_money(money) для передачі нового значення
приватної локальної змінної money (зміна виконується тільки якщо
метод check_money(money) повертає значення True);
● публічний метод get_money() для отримання поточного обсягу
коштів (грошей);

● публічний метод add_money(money) для додавання коштів з об'єкта
money класу Money до коштів поточного об'єкта;
● приватний метод класу check_money(money) для перевірки
коректності обсягу коштів у параметрі money(повертає True, якщо
значення коректне, і False - в іншому випадку).
Перевірка коректності виконується за критерієм: параметр money має
бути цілим числом, більшим або рівним нулю.
Приклад використання класу Money для перевірки функціоналу:
money1 = Money(10)
money2 = Money(20)
money1.set_money(100)
money2.add_money(money1)
print(money1.get_money()) # Output: 100
print(money2.get_money()) # Output: 120

# Завдання 3.

● set_title(self, title) - запис у локальну приватну властивість title
об'єктів класу Book значення title;
● set_author(self, author) - запис у локальну приватну властивість
author об'єктів класу Book значення author;
● set_price(self, price) - запис у локальну приватну властивість price
об'єктів класу Book значення price;
● get_title(self) - отримання значення локальної приватної властивості
title об'єктів класу Book;
● get_author(self) - отримання значення локальної приватної
властивості author об'єктів класу Book;
● get_price(self) - отримання значення локальної приватної властивості
price об'єктів класу Book;
Об'єкти класу Book передбачається створювати командою:

book = Book(author, title, price)

При цьому в кожному об'єкті мають створюватися приватні локальні
властивості:
__author - рядок з ім'ям автора;
__title - рядок із назвою книги;
__price - ціле число з ціною книги.
Створити 3 екземпляра класу Book для перевірки методів класу.
