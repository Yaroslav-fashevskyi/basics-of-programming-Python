# Завдання 1.
Створіть систему для керування користувачами та їхніми
банківськими рахунками. У цій системі повинні бути наступні класи:
1. User: Цей клас представляє користувача системи. У кожного
користувача є наступні атрибути:
● Ім'я (name)
● Прізвище (surname)
● Вік (age)
● Список банківських рахунків (accounts)
2. BankAccount: Цей клас представляє банківський рахунок. У
кожного рахунку є наступні атрибути:
● Номер рахунку (account_number)
● Баланс (balance)
● Власник (owner) - об'єкт класу User
3. BankSystem: Цей клас відповідає за управлінням користувачами
та їхніми рахунками. Він має такі методи:
● create_user(name, surname, age): Створює нового користувача з
заданими даними та повертає об'єкт класу User.
● create_account(user, initial_balance): Створює новий банківський
рахунок для заданого користувача з початковим балансом та
повертає об'єкт класу BankAccount.
● deposit(account, amount): Здійснює поповнення балансу на рахунку
на задану суму.
● withdraw(account, amount): Здійснює зняття з рахунку заданої суми.
● transfer(sender_account, receiver_account, amount): Здійснює переказ
коштів з рахунку відправника на рахунок отримувача на задану суму.

Класи повинні бути спроектовані таким чином, щоб уникнути
прямого доступу до атрибутів ззовні, а замість цього використовувати

методи для взаємодії з об'єктами. Наприклад, метод create_account класу
BankSystem має бути відповідальним за створення об'єкта BankAccount
та додавання його до списку рахунків користувача.

Приклад використання системи:

bank_system = BankSystem()
user1 = bank_system.create_user("John", "Doe", 35)
account1 = bank_system.create_account(user1, 1000)
bank_system.deposit(account1, 500)
bank_system.withdraw(account1, 200)
user2 = bank_system.create_user("Alice", "Smith", 28)
account2 = bank_system.create_account(user2, 1500)
bank_system.transfer(account1, account2, 300)

# Завдання 2.
Розробіть систему для керування автомобілями та їх
характеристиками. У цій системі повинні бути наступні класи:
1. Car: Цей клас представляє автомобіль. У кожного автомобіля є
наступні атрибути:
● Марка (brand)
● Модель (model)
● Рік випуску (year)
● Швидкість (speed)
● Потужність (power)
● Колір (color)
2. Driver: Цей клас представляє водія. У кожного водія є наступні
атрибути:
● Ім'я (name)

● Вік (age)
● Досвід водіння (driving_experience)
3. Race: Цей клас відповідає за проведення автогонок. Він має такі
методи:
● start_race(car1, car2): Проводить гонку між двома автомобілями та
визначає переможця на основі їхньої швидкості, потужності та
досвіду водіння водіїв.
● print_winner(winner): Виводить інформацію про переможця гонки.

Класи повинні бути спроектовані таким чином, щоб вони могли
взаємодіяти між собою, наприклад, метод start_race класу Race повинен
приймати два об'єкти класу Car та визначати переможця на основі їхніх
характеристик.

Приклад використання:
car1 = Car("BMW", "X5", 2022, 250, 300, "Black")
car2 = Car("Audi", "A6", 2023, 240, 280, "White")
driver1 = Driver("John", 35, 15)
