Оголосіть клас з іменем Car який містить такі атрибути:
1. brand: Рядок, що представляє марку автомобіля.
2. model: Рядок, що представляє модель автомобіля.
3. year: Ціле число, що представляє рік випуску автомобіля.
Потрібно реалізувати наступні методи:
1. __init__(): Конструктор класу, який приймає параметри brand,
model і year, та ініціалізує відповідні атрибути.
2. display_info(): метод, що виводить інформацію про автомобіль
(марка, модель, рік) в консоль.
3. change_model(): метод, який дозволяє змінити модель
автомобіля на нову модель. Метод приймає нову модель як
параметр і оновлює відповідний атрибут model.
4. calculate_age(): метод, який обчислює вік автомобіля,
використовуючи поточний рік і рік випуску автомобіля. Метод
повертає ціле число - вік автомобіля.
Продемонструйте роботу усіх методів в звіті.
